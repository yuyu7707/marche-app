以下を順番に実行し、結果をまとめてください。途中で失敗しても最後まで実行します。

1. `uv run ruff format --check .` — コードの整形チェック。指摘があれば `uv run ruff format .` で直してよい（整形だけで、動きは変わらない）
2. `uv run ruff check .` — 静的解析（使っていない import、未定義の名前、書き方の誤りなど）
3. `uv run pytest -q` — テスト

## 報告の形式

- 3つそれぞれについて「通過 / 失敗」と、失敗した場合はその件数
- `ruff format` で整形し直したファイルがあれば、その一覧
- `ruff check` の指摘は、ファイルと行と内容（ルールのコード、例: F401）を1件ずつ。初学者向けに「なぜ問題か」を1行添える。直し方の提案はするが、指示があるまで直さない
- 落ちたテストは、テスト名と失敗理由を1件ずつ。実装のバグかテストの書き間違いかの見立てを添える
- 全て通過なら「コミットしてよい状態です」と1行で
