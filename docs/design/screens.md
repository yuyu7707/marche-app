# 画面設計

> 参考解答（[docs/spec/02_screens.md](../spec/02_screens.md)）をもとに、自分のユーザーストーリーに合わせて決めたもの。各画面の細かい動きは参考解答を見る。

## 参考解答から変えたこと

- **S14 管理者の注文一覧をコアに入れた**（ストーリー「管理者として、全ての注文を確認したい。購入者からの問い合わせに答えたいから」のため）。全商品の確認は拡張 E15 のまま

## 画面一覧

### 今日作る範囲（Day4）

| 画面名 | URL | ログインが必要か | 使えるロール | 表示するもの・できること |
|-|-|:-:|-|-|
| S1 トップ（商品一覧） | `/` | 不要 | 誰でも | 公開中の商品。写真、商品名、価格、生産者名、在庫（0 なら「売り切れ」） |
| S2 商品詳細 | `/products/<id>` | 不要 | 誰でも（非公開は出品者・管理者だけ。それ以外は 404） | 写真、価格、紹介文、生産者名、いま買える数。数量（1〜10）を選んで「カートに入れる」。レシピ提案（拡張 E19） |
| S3 会員登録 | `/register` | 不要 | 未ログイン | 名前、メール、パスワード、「購入者 / 生産者」の選択（管理者は選べない） |
| S4 ログイン | `/login` | 不要 | 未ログイン | メール、パスワード |
| S5 カート | `/cart/` | 不要 | 誰でも | 商品、単価、数量（変更・0 で外す）、小計、合計。「注文して支払いへ進む」（注文はログインが必要） |
| S6 出品管理 | `/producer/products` | 必要 | 生産者 | 自分の商品の一覧。公開状態、在庫。「公開する / 非公開にする」「削除」「編集」「商品を登録する」 |
| S7 商品の登録 | `/producer/products/new` | 必要 | 生産者 | 商品名、価格（50〜100,000円）、在庫数（0〜999）、紹介文、写真（JPEG/PNG/WebP、5MB まで）、公開するか |
| S8 商品の編集 | `/producer/products/<id>/edit` | 必要 | 生産者（自分の商品だけ。他人のは 403） | S7 と同じ項目。AI で紹介文を下書き（拡張 E18） |
| S9 注文詳細 | `/orders/<id>` | 必要 | 注文した本人・管理者（他人のは 403） | 注文番号、注文日時、状態、明細（商品名・単価・数量・小計）、合計 |

### 平日課題（平日）

| 画面名 | URL | ログインが必要か | 使えるロール | 表示するもの・できること |
|-|-|:-:|-|-|
| S10 支払い完了 | `/orders/<id>/complete` | 必要 | 注文した本人・管理者 | Stripe から戻る画面。「ご注文ありがとうございます」。未確定なら「確認中」で5秒ごとに再読み込み |
| S11 支払い中断 | `/orders/<id>/cancel` | 必要 | 注文した本人・管理者 | Stripe で「戻る」を押したときの画面。「この注文を取り消す」 |
| S12 注文履歴 | `/orders/` | 必要 | ログインユーザー全員 | 自分の注文を新しい順に。注文日時、合計、状態。行から S9 へ |
| S13 売上 | `/producer/sales` | 必要 | 生産者 | 自分の商品ごとの販売数と売上（支払い済みだけ）、合計 |
| **S14 注文一覧（管理）** | `/admin/orders` | 必要 | **管理者** | **全ての注文を新しい順に。注文番号、注文日時、注文者の名前とメール、合計、状態。行から S9 へ** |

### 画面ではない URL（POST だけ）

値を変える操作は全て POST にする（GET のリンクで操作できると、リンクを踏ませるだけで操作されたり、クローラーが AI を呼んで費用がかかったりするため）。

| URL | ログインが必要か | 使えるロール | 内容 | 時期 |
|-|:-:|-|-|:-:|
| `POST /logout` | 必要 | ログインユーザー | ログアウト | Day4 |
| `POST /cart/add/<id>` | 不要 | 誰でも | カートに入れる（数量） | Day4 |
| `POST /cart/update/<id>` | 不要 | 誰でも | 数量を変える（0 なら外す） | Day4 |
| `POST /orders/` | 必要 | ログインユーザー | カートから注文を作る（在庫と金額はサーバーで確認・計算）。平日課題で Stripe へリダイレクト | Day4 |
| `POST /producer/products/<id>/toggle` | 必要 | 生産者（自分の商品だけ） | 公開 / 非公開 の切り替え | Day4 |
| `POST /producer/products/<id>/delete` | 必要 | 生産者（自分の商品だけ） | 削除（注文がある商品は削除できない → 非公開にする） | Day4 |
| `POST /stripe/webhook` | 不要 | Stripe | 支払いの確定（CSRF の対象外、署名で確かめる） | 平日 |
| `POST /producer/products/<id>/ai-description` | 必要 | 生産者（自分の商品だけ） | AI に紹介文の下書きを作らせ、S8 を返す（保存はしない） | 拡張 E18 |
| `POST /products/<id>/recipes` | 必要 | ログインユーザー | AI にレシピを提案させ、S2 を返す | 拡張 E19 |

S11 の「この注文を取り消す」は S11 のフォームから POST で送る（`/orders/<id>/cancel` への POST）。

## ユーザーストーリーと画面

| ストーリー | 画面 |
|-|-|
| 利用者：会員登録で立場を選ぶ | S3 |
| 購入者：商品の一覧と詳細を見る | S1、S2 |
| 購入者：カートの数量を変える・外す | S5 |
| 購入者：まとめてカードで支払う | S5 → Stripe → S10 |
| 購入者：支払い途中で取り消す | S11 |
| 購入者：注文確認のメール | 画面なし（`services/mail.py`） |
| 購入者：注文履歴で金額を確かめる | S12、S9 |
| 購入者：レシピ提案（拡張 E19） | S2 |
| 生産者：写真付きで登録 | S7 |
| 生産者：後から直す・削除する | S6、S8（注文がある商品は削除できず、非公開にする） |
| 生産者：非公開で準備して公開 | S6 |
| 生産者：在庫より多く売らない | S2、注文作成（いま買える数で確認） |
| 生産者：売上を見る | S13 |
| 生産者：他人に編集させない | S8 ほか（所有者でなければ 403） |
| 生産者：AI 下書き（拡張 E18） | S8 |
| 管理者：全ての注文を確認 | **S14**、S9 |
| 管理者：全ての商品を確認 | 拡張 E15 |

## ナビゲーション

| ロール | ヘッダーのメニュー |
|-|-|
| 未ログイン | 商品一覧（ロゴ）、カート、ログイン、会員登録 |
| 購入者 | 商品一覧、カート、注文履歴、ログアウト |
| 生産者 | 商品一覧、カート、注文履歴、出品管理、売上、ログアウト |
| 管理者 | 商品一覧、カート、注文履歴、**注文一覧（管理）**、ログアウト |

## 認可（参考解答に足すもの）

| 対象 | 操作 | 許可 | 違反したとき | 書く場所 |
|-|-|-|-|-|
| 管理者の画面（`/admin/`） | 全て | ロールが admin | 未ログインはログインへ、他のロールは 403 | `@role_required(Role.ADMIN)` |

その他は参考解答の「認可のルール」と同じ。
